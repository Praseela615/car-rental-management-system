# DriveEase – Car Rental Management System

A professional responsive frontend project for an MCA/college web development assignment.

## Features
- Responsive homepage with hero section
- Dynamic car listings
- Search by model/name
- Filter by category, fuel type and price
- Car details modal
- Booking form
- Form validation
- Rental date calculation
- Estimated booking total
- LocalStorage booking history
- Clear booking history
- Dark mode
- Responsive mobile navigation
- Contact/about sections
- GitHub Pages compatible

## Technologies
- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
- Unsplash image URLs

## How to run
1. Download/extract the project.
2. Open `index.html` in a browser.
3. For GitHub Pages, upload all files/folders to your repository root.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → /root.

## Suggested viva explanation
DriveEase is a client-side car rental management system. JavaScript stores the car data in an array and dynamically creates car cards. Search and filters modify the displayed array. The booking form validates customer details and rental dates. The total price is calculated from the selected car's daily rate and rental duration. Confirmed bookings are stored in browser LocalStorage so that booking history remains available after refreshing the page.

## Important
This is a frontend academic project. It does not process real payments or communicate with a real rental company backend.
